Hãy code một website thư mời lễ tốt nghiệp bằng ReactJS, ưu tiên mobile-first, responsive chuẩn cho điện thoại. Giao diện lấy cảm hứng từ ảnh thư mời mẫu: dễ thương, nhẹ nhàng, thanh lịch, tông xanh pastel – trắng – xanh dương.

Tech stack:
- ReactJS + Vite
- Tailwind CSS
- Framer Motion cho animation
- React Router
- Supabase: Auth, Database, Storage
- React Hook Form + Zod
- Google Fonts
- Có thể dùng lucide-react cho icon
- Có thể dùng react-day-picker hoặc custom calendar
- Có thể dùng leaflet hoặc Google Maps iframe để ghim địa điểm

Yêu cầu tổng thể:
Thiết kế website như một mini landing page thư mời tốt nghiệp, có cảm giác như mở một tấm thiệp online. Giao diện phải đẹp, mềm mại, nhiều khoảng trắng, bo góc lớn, có shadow nhẹ, hiệu ứng fade/slide/parallax tinh tế. Ưu tiên trải nghiệm trên mobile, desktop vẫn đẹp nhưng không cần quá phức tạp.

Cấu trúc route:
1. /login
2. /
3. /album
4. /admin hoặc /album/manage cho chủ sở hữu quản lý ảnh

- Hiệu ứng khi vào trang: card fade in, title scale nhẹ, feather/icon bay nhẹ.

5. RSVP Form
Form xác nhận tham dự, không cần login:
Fields:
- Họ và tên
- Số điện thoại
- Bạn sẽ tham dự chứ?
  - Có, mình sẽ đến
  - Có thể
  - Tiếc quá, mình không đến được
- Số người đi cùng
- Ghi chú / lời nhắn ngắn

Khi submit:
- Validate bằng Zod.
- Lưu vào bảng Supabase `rsvps`.
- Hiển thị toast thành công.
- Có loading state.

Schema Supabase:
Table `rsvps`:
- id uuid primary key default gen_random_uuid()
- name text not null
- phone text
- attendance_status text not null
- guest_count int default 0
- note text
- created_at timestamp default now()

6. Wishes Form
Form gửi lời chúc:
Fields:
- Tên người gửi
- Lời chúc
- Chọn icon cảm xúc: 🎓 💙 ✨ 🥹 🌸 🎉
Submit xong lưu vào bảng `wishes`.

Table `wishes`:
- id uuid primary key default gen_random_uuid()
- sender_name text not null
- message text not null
- emoji text
- created_at timestamp default now()

Hiển thị một số lời chúc mới nhất bên dưới dưới dạng card nhỏ xinh, có animation.

Trang `/album`:
Mục đích: album ảnh lễ tốt nghiệp giống ứng dụng locket dễ thương.

Chức năng:
- Người xem có thể xem album không cần login.
- Chỉ tài khoản chủ sở hữu mới được thêm/sửa/xóa ảnh.
- Layout album có các chế độ:
  1. Grid layout
  2. Masonry / Pinterest layout
  3. Carousel xoay vòng
  4. Flow layout mềm mại
- Có nút đổi layout nếu user là admin.
- Có filter theo tag: “Bạn bè”, “Gia đình”, “Sân trường”, “Khoảnh khắc vui”, “Ảnh yêu thích”.

Table `album_photos`:
- id uuid primary key default gen_random_uuid()
- image_url text not null
- caption text
- tag text
- frame_type text
- sticker_data jsonb
- layout_order int
- created_at timestamp default now()

Supabase Storage:
- Bucket: `graduation-album`
- Upload ảnh vào bucket này.
- Lưu public URL vào `album_photos.image_url`.

Trang `/login`:
- Chỉ có một tài khoản chủ sở hữu.
- Login bằng Supabase Auth email/password.
- UI đơn giản, dễ thương, cùng tone màu.
- Sau khi login thành công chuyển về `/album/manage` hoặc hiện nút upload trong `/album`.

Chức năng upload ảnh:
- Cho phép chủ sở hữu upload ảnh từ máy.
- Cho phép mở camera chụp ảnh nếu trình duyệt hỗ trợ.
- Sau khi chọn/chụp ảnh, hiển thị màn preview.
- Có thể thêm caption, tag.
- Có thể chọn frame:
  - Polaroid trắng
  - Blue ribbon frame
  - Graduation cap frame
  - Heart pastel frame
- Có thể thêm sticker/icon dễ thương:
  🎓 💙 ✨ 🌸 🪽 📸 🥹 🎉
- Sticker có thể kéo thả cơ bản nếu làm được, nếu không thì chọn sticker overlay cố định ở góc ảnh.
- Upload ảnh đã chọn lên Supabase Storage.
- Lưu metadata vào database.

Animation:

Yêu cầu code:
- Viết code hoàn chỉnh, chạy được.
- Tách component rõ ràng.
- Có file `.env.example`:
  VITE_SUPABASE_URL=
  VITE_SUPABASE_ANON_KEY=
  VITE_GOOGLE_MAPS_EMBED_URL=
- Có hướng dẫn tạo bảng SQL Supabase.
- Có hướng dẫn tạo bucket Supabase Storage.
- Có RLS policy cơ bản:
  - Ai cũng insert được RSVP và wishes.
  - Ai cũng read được wishes và album_photos.
  - Chỉ authenticated owner mới insert/update/delete album_photos.
- Không hardcode Supabase key.
- Có loading, empty state, error state.
- Code sạch, dễ mở rộng.
